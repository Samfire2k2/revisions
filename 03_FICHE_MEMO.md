# CHAP. 1 — BILAN

## Bilan fonctionnel (valeurs BRUTES)

| EMPLOIS | RESSOURCES |
|---|---|
| **Actif immobilisé BRUT** + frais d'émission des emprunts | **Capitaux propres** + **A&P (colonne actif)** + **provisions R&C** + **dettes financières − CBC − SCB** |
| **ACE** : stocks + avances versées + créances clients + autres créances expl. + **CCA** | **DE** : avances reçues + fournisseurs + dettes fiscales/sociales + **PCA** |
| **ACHE** : créances diverses + **VMP** | **DHE** : dettes sur immo + dettes d'IS + autres dettes diverses |
| **TA** : disponibilités | **TP** : **CBC + SCB** |

**Contrôle : Total actif = Total passif = Total BRUT du bilan comptable.**

## Les agrégats

```
FRNG  = Ressources stables − Emplois stables
BFRE  = ACE − Dettes d'exploitation
BFRHE = ACHE − Dettes hors exploitation
BFR   = BFRE + BFRHE
TN    = Trésorerie d'actif − Trésorerie de passif

              ★ TN = FRNG − BFR ★
```

**Les 4 inversions** : `FRNG = TN + BFR` · `BFR = FRNG − TN` · `BFRHE = BFR − BFRE` · `DE = ACE − BFRE`

## Variation de la TN par 2 méthodes

```
Méthode 1 :  ΔTN = ΔFRNG − ΔBFR
Méthode 2 :  ΔTN = ΔTrésorerie d'actif − ΔTrésorerie de passif
```

## Le sens des variations

> **ACTIF circulant ↑ → BFR ↑** &nbsp;·&nbsp; **DETTES circulantes ↑ → BFR ↓**

## Diagnostic express

| FRNG | BFR | TN | Lecture |
|---|---|---|---|
| + | + petit | + | 💚 Sain |
| + | + grand | − | 🟠 **Croissance mal maîtrisée** (le cas type) |
| + | − | ++ | 💚 Distribution, idéal |
| − | + | −− | 🔴 Danger maximal |
| − | − | + | 🟠 Fragile mais tenable |

## Bilan financier (valeurs NETTES)

**Actif fictif à éliminer** (de l'actif ET des capitaux propres) : frais d'établissement, frais de R&D, frais d'émission des emprunts, primes de remboursement des obligations.

**Retraitements** : reclassements +1an/−1an (notes de bas de bilan) · dividendes à distribuer → dettes < 1 an · provisions R&C justifiées → dettes selon échéance, non justifiées → capitaux propres · PCA = dettes.

```
FRF = Capitaux permanents − Actif > 1 an
FRF = Actif < 1 an − Dettes < 1 an        ← les deux doivent être égaux
```

## Ratios

| Ratio | Formule | Norme |
|---|---|---|
| Couverture des capitaux investis | Ressources stables / (Immo + BFRE) | ≈ 100 %, **90 % = bon** |
| Taux d'endettement | Endettement **total** / Capitaux propres | ≈ 1 |
| Capacité de remboursement | Dettes financières / CAF | **< 3-4 ans** |
| Autonomie financière | CP / Dettes | **> 0,5** |
| Indépendance financière | CP / Capitaux permanents | ≈ 0,5 |
| Solvabilité générale | Actif réel / Dettes | **> 1** |
| Liquidité générale | Actif < 1an / Dettes < 1an | **> 1** |
| Liquidité réduite | (Actif < 1an − stocks) / Dettes < 1an | > 1 souhaitable |
| Liquidité immédiate | (Trésorerie + VMP) / Dettes < 1an | **toujours < 1** |

*Les 3 liquidités sont emboîtées → forcément décroissantes.*

# CHAP. 2 — CAF, ETE, ESOG

## EBE

```
  Ventes de mses + Production vendue + Production stockée
+ Production immobilisée + Subventions d'exploitation
− Achats mses − Δstocks mses − Achats MP − Δstocks MP
− Autres achats et charges externes − Impôts et taxes
− Salaires − Charges sociales
────────────────────────────────────────────────────────
= EBE
```
**PAS dans l'EBE** : DAP, RAP, autres produits/charges, financier, exceptionnel, participation, IS.

## CAF — méthode ADDITIVE

```
  RNC  + VCEAC  − PCEA  + DAP  − RAP  =  CAF
```
*« Je pars du résultat et j'annule les 4 fantômes. Charges fantômes en +, produits fantômes en −. »*

## CAF — méthode SOUSTRACTIVE

```
  EBE
+ autres produits d'expl. (sauf reprises)   − autres charges d'expl. (sauf dotations)
+ produits financiers (sauf reprises)       − charges financières (sauf dotations)
+ produits except. (sauf reprises et PCEA)  − charges except. (sauf dotations et VCEAC)
− participation des salariés                − impôt sur les bénéfices
────────────────────────────────────────────────────────────────────────
= CAF
```
*Règle unique : on balaie tout le compte de résultat en sautant les 4 fantômes.*

## ★ Les dividendes (l'inconnue la plus fréquente)

```
╔═══════════════════════════════════════════════════════════════╗
║  Dividendes N =  Résultat N−1  −  Δ(TOUTES les réserves)      ║
║                                −  Δ(report à nouveau)         ║
╚═══════════════════════════════════════════════════════════════╝
```

## Autofinancement

```
AF brut = CAF − dividendes
AF net  = AF brut − (DAP − RAP)
```

## ETE et ESOG

```
ETE  = EBE − ΔBFRE          ESOG = CAF − ΔBFR
```
**Inversions** : `ΔBFRE = EBE − ETE` · `EBE = ETE + ΔBFRE` · `ΔBFR = CAF − ESOG`

**EBE vs ETE** : l'EBE est un **résultat**, l'ETE une **trésorerie**. L'ETE est *« l'indicateur le plus sensible aux variations de l'activité »*.

## Tableau Origine/Utilisation du FRNG

| EMPLOIS | RESSOURCES |
|---|---|
| Dividendes | CAF |
| Acquisitions d'immobilisations | Cessions (PCEA) |
| Frais d'émission des emprunts | Émission d'emprunts |
| Remboursement d'emprunts | Augmentation de capital |

**Ressources − Emplois = ΔFRNG** → sert à retrouver un poste manquant par différence.

**L'outil universel** : `Valeur début + Augmentations − Diminutions = Valeur fin`

# CHAP. 3 — RENTABILITÉ

## Les définitions

```
Re avant impôts = Résultat économique / Actif économique
Re après impôts = Re avant impôts × (1 − s)
Rf              = RNC / Capitaux propres HORS RÉSULTAT

Actif économique = CP hors résultat + Dettes financières (hors CBC)
                 = Immobilisations + BFRE

Résultat économique = RNC + IS + charges d'intérêts    (= RAII)   ← par défaut
                    = Résultat d'exploitation           ← si l'énoncé le dit

s = IS / (IS + RNC) = IS / Résultat avant impôts
i = charges d'intérêts / Dettes financières
```

> **★ Prends toujours le RAII si on te demande de vérifier par l'effet de levier.** C'est le seul qui fait boucler la formule.
> **Entreprise en perte → IS = 0 → s = 0 % → Re après = Re avant.**

## ★ La formule maîtresse

```
╔═══════════════════════════════════════════════════════════════════════╗
║   Rf  =  Re(1−s)   +   (Re − i) × (D/CP) × (1−s)                      ║
║          ─────────      ──────────────────────────                    ║
║          Re après imp.       EFFET DE LEVIER                          ║
╚═══════════════════════════════════════════════════════════════════════╝

Effet de levier = Rf − Re après impôts
```

## Les 5 inversions de la formule

```
                Rf − Re(1−s)
   i    =  Re − ─────────────────
                 (D/CP)(1−s)

  D/CP  =   [Rf − Re(1−s)] / [(Re − i)(1−s)]

                Rf/(1−s) + i(D/CP)
   Re   =  ──────────────────────────
                   1 + D/CP

  (1−s) =   Rf / [Re + (Re − i)(D/CP)]
```

## Les 3 configurations

| | Conséquence |
|---|---|
| **Re > i** | ✅ Effet de **LEVIER** — Rf > Re après impôts |
| **Re = i** | ⚪ Effet **NUL** |
| **Re < i** | 🔴 Effet de **MASSUE** — Rf < Re après impôts |

**Levier nul aussi si D/CP = 0.** · **Limite prudentielle : D/CP ≤ 1.**

## Risque d'exploitation

```
Taux de MCV       = (CA − CV) / CA
Seuil de rentab.  = CF / taux de MCV
Marge de sécurité = CA − SR
Indice de sécurité = (CA − SR) / CA

LO = M/CV / RE  =  1 / indice de sécurité  =  Δ%RE / Δ%CA
```
*LO = 5 → si le CA varie de 1 %, le RE varie de 5 %, dans les deux sens.*
**Beaucoup de charges fixes → LO élevé → risque élevé.**

**Réduire le risque** : baisser les CF (sous-traitance, intérim, flexibilité), augmenter le taux de M/CV → abaisser le SR.

**Point mort (date)** = `(SR / CA) × 360`

## Le plan de réponse en 10 étapes

```
1. Résultat avant impôts = RNC + IS      6. Re après = Re avant × (1−s)
2. s = IS / résultat avant impôts        7. Rf = RNC / CP hors résultat
3. Résultat éco = RNC + IS + intérêts    8. i = intérêts / DF
4. Actif éco = CP hors résultat + DF     9. VÉRIFIER par la formule du levier
5. Re avant = (3)/(4)                   10. Commenter : levier ou massue ?
```

# CHAP. 4 — BFR NORMATIF

## Le principe

```
Montant du poste = DS × RS × (CAHT/360)

DS = (Valeur MOYENNE du poste × 360) / Flux ANNUEL du poste
RS = Flux ANNUEL du poste / CAHT      (ou coût unitaire / PV unitaire HT)

★ DS × RS = Valeur moyenne × 360 / CAHT   ← le flux se simplifie : contrôle imparable
```

## Le tableau

| Postes | DS | RS | Besoins | Dégagements |
|---|---|---|---|---|
| Stocks (MP, en-cours, PF, mses) | | | ✔ | |
| Clients | | | ✔ | |
| TVA déductible | | | ✔ | |
| Fournisseurs | | | | ✔ |
| Dettes de personnel | | | | ✔ |
| Organismes sociaux | | | | ✔ |
| TVA collectée | | | | ✔ |

```
BFRE normatif en jours = Σ Besoins − Σ Dégagements
BFRE normatif en €     = jours × CAHT/360
```
> **Règle mémo : ACTIF du bilan = BESOIN · PASSIF du bilan = DÉGAGEMENT.**

## Les dénominateurs des DS

| Poste | Flux annuel |
|---|---|
| Stock marchandises | Coût d'achat des mses **vendues** = achats + Δstock |
| Stock MP | Coût d'achat des MP **utilisées** |
| Stock PF | Coût de production des produits **vendus** |
| Clients | **CA TTC** |
| Fournisseurs | **Achats TTC** |
| TVA collectée | CAHT × taux |
| TVA déductible | Achats HT × taux |
| Personnel | Charges de personnel |

## ★ Les conventions de délais

| Énoncé | DS |
|---|---|
| Comptant | **0** |
| 30 jours | 30 |
| 30 jours **FIN DE MOIS** | 30 + **15** = 45 |
| 60 jours fin de mois | 75 |
| TVA le **X du mois suivant** | **15 + X** |
| Salaires fin de mois | **15** |
| Cotisations le 15 du mois suivant | 15 + 15 = 30 |

*Les 15 jours = la durée moyenne d'attente dans le mois (30/2).*

**Délais pondérés** : `DS = Σ (% × délai)` → *ex : 10 % comptant + 90 % à 50 j = 45 jours*

## ★ Les RS en pourcentages (technique « je pose x = le CA »)

```
Prix d'achat = 50 % du PV        →  RS stock 0,50 · RS fourn. 0,60 · RS TVA déd. 0,10
Marge 50 % SUR LE PRIX D'ACHAT   →  RS stock 0,67 · RS fourn. 0,80 · RS TVA déd. 0,13
30 % export (pas de TVA)         →  RS clients 1,14 · RS TVA coll. 0,14
2 taux de TVA (40 % à 5,5 %,
     60 % à 20 %)                →  RS clients 1,142 · RS TVA coll. 0,142
```

## ★ Salaires et cotisations

Raisonner sur **un salaire brut de 100** :
```
Brut 100 + patronales 35  =  COÛT ENTREPRISE 135
   dont net versé : 100 − 25 (salariales) = 75
   dont cotisations : 25 + 35 = 60

RS dettes de personnel      = (75/135) × (part des charges de personnel dans le CA)
RS dettes organismes sociaux = (60/135) × (idem)
Contrôle : la somme des 2 RS = la part totale des charges de personnel  ✅
```

## ★ Impact d'une modification

```
Impact en jours de CAHT = Δ Durée de stockage × RS
```
*Ex : délai clients de 45 → 40 jours, RS = 1,20 → gain de 6 jours de CAHT.*

**Économie vs secteur** = `(BFR entreprise − BFR secteur) × CAHT/360`

## Intérêts / limites

| Intérêts | Limites |
|---|---|
| Comprendre l'origine de chaque poste | Hypothèses simplificatrices (durées moyennes, CA régulier, proportionnalité) |
| Cibler les actions sur la DS ou le RS | Inadapté aux activités **saisonnières** |
| Mesurer l'incidence d'une modification | Ignore le conjoncturel et le hors exploitation |
| Prévoir le BFRE à partir d'un CA prévisionnel | Hors amortissements (non décaissables) |
| Comparer au secteur | Diffère du BFRE du bilan (stock moyen ≠ stock final) |

**Lien avec la rentabilité** : `Re = RE / (Immo + BFRE)` → **BFRE ↑ ⟹ Re ↓**

**Réduire le poste clients** : raccourcir les délais contractuels · plus de clients particuliers (comptant) · **affacturage** (le factor devient propriétaire des créances, prend le risque de non-recouvrement, contre commission) · escompte de règlement.

# CHAP. 5 — TABLEAU DE FLUX

```
┌─────────────────────────────────────────────────────────────────┐
│  Résultat net                                                   │
│ + DAP nettes de reprises (SAUF sur ACTIF CIRCULANT)             │
│ − Plus-value de cession (PCEA − VCEAC)                          │
│ − Transfert de charges aux frais d'émission des emprunts        │
│ ═══════════════════════════════════════════════════════════════ │
│ = MARGE BRUTE D'AUTOFINANCEMENT (MBA)                           │
│ − Variation du BFR (en valeurs NETTES) :                        │
│      Stocks (− si ↑) · Créances expl. (− si ↑)                  │
│      Dettes expl. (+ si ↑) · Autres créances (− si ↑)           │
│      Autres dettes (+ si ↑)                                     │
│ ═══════════════════════════════════════════════════════════════ │
│ = FLUX NET GÉNÉRÉ PAR L'ACTIVITÉ                        (A)     │
├─────────────────────────────────────────────────────────────────┤
│ − Acquisitions d'immobilisations                                │
│ + Cessions d'immobilisations (PCEA)                             │
│ + Réduction d'immobilisations financières (prêts remboursés)    │
│ ± Variation dettes/créances sur immobilisations                 │
│ = FLUX D'INVESTISSEMENT                                 (B)     │
├─────────────────────────────────────────────────────────────────┤
│ − Dividendes versés                                             │
│ ± Incidence des variations de capital (Δcapital + Δprimes)      │
│ + Émissions d'emprunts   − Remboursements d'emprunts            │
│ = FLUX DE FINANCEMENT                                   (C)     │
├─────────────────────────────────────────────────────────────────┤
│ ★ A + B + C = Trésorerie clôture − Trésorerie ouverture         │
│   Trésorerie = Disponibilités + VMP − CBC − SCB                 │
└─────────────────────────────────────────────────────────────────┘
```

## Les signes

```
ACTIF ↑ → −     ACTIF ↓ → +     DETTE ↑ → +     DETTE ↓ → −
```

## Où trouver quoi

| Donnée | Source |
|---|---|
| Acquisitions | Colonne **« Augmentations »** du tableau des IMMOBILISATIONS |
| Valeur d'origine des cessions | Colonne **« Diminutions »** du tableau des IMMOBILISATIONS |
| Amortissements des biens cédés | Colonne **« Diminutions »** du tableau des AMORTISSEMENTS |
| Dotations de l'exercice | Colonne **« Augmentations »** du tableau des AMORTISSEMENTS et PROVISIONS |
| Reprises | Colonne **« Diminutions »** du tableau des PROVISIONS |
| Émissions / remboursements | `DF fin (hors CBC) = DF début (hors CBC) + émissions − remboursements` |
| Augmentation de capital | Δ capital + Δ primes d'émission |
| Dividendes | Résultat N−1 − Δréserves − ΔRAN |

## Le tableau des plus/moins-values

```
VNC = Valeur d'origine − Amortissements pratiqués
+/− value = Prix de cession − VNC
```
*Les titres de participation ne s'amortissent pas → VNC = valeur d'origine.*

## MBA vs CAF

| | Dépréciations d'actif circulant |
|---|---|
| **CAF** | **incluses** |
| **MBA** | **exclues** |

# CHAP. 6 — INTÉRÊTS SIMPLES / ESCOMPTE / DÉCOUVERT

## Intérêts simples

```
I = C₀ × t × n          Vₙ = C₀ (1 + t × n)

n = j/360  (jours)   ·   m/12 (mois)   ·   q/24 (quinzaines)
```
**Inversions** : `C₀ = Vₙ/(1+tn)` · `t = I/(C₀n)` · `n = I/(C₀t) = (Vₙ−C₀)/(C₀t)`

**Année financière = 360 jours** (avantage le prêteur) — **MAIS 365 pour le taux réel**.

**Quinzaines** : seules les quinzaines **civiles complètes** comptent (1-15, 16-fin). Diviser par **24**.

## Escompte

```
Escompte      : e = VN × t × j/360
Valeur actuelle : Va = VN × [1 − t × j/360]
Agio HT       = escompte + commissions HT
Agio TTC      = escompte + commissions × 1,2      (TVA sur commissions seulement)
Net porté au compte = VN − Agio TTC

                     Agio HT × 365
   Taux réel  =  ───────────────────────────────
                 (VN − Agio HT) × durée RÉELLE
```

**Durée FACTURÉE = durée réelle + jours de banque.** La durée **réelle** (sans jours de banque) sert au taux réel.

**Le taux réel > taux nominal, TOUJOURS.** 3 causes : jours de banque · commissions fixes · 360 vs 365.

| Commission | Traitement |
|---|---|
| Fixe par effet | + en € × nombre d'effets |
| **Endos, proportionnelle au temps** | **s'ajoute AU TAUX** (11 % + 0,60 % = 11,60 %) |
| Proportionnelle à la valeur | VN × taux |

## Équivalence d'effets

```
VN_nouveau × [1 − t × j_nouv/360]  =  Σ VN_i × [1 − t × j_i/360]
```
Toutes les durées comptées depuis la **date d'équivalence**.

**Inversion pour le taux :**
```
                 VN_nouveau − Σ VN_anciens
   t  =  ───────────────────────────────────────────
         [VN_nouv × j_nouv − Σ (VN_i × j_i)] / 360
```

## Découvert

```
Nombres débiteurs = Σ (solde débiteur × nb de jours)
Intérêts = Nombres débiteurs × t/360  =  Nombres débiteurs × t(%)/36 000

Agios HT = Intérêts + CPFD + Commission de dépassement + Commission de compte

Taux réel = Agios HT × 365 / Nombres débiteurs
TAEG (%)  = Agios retenus × 36 500 / Nombres débiteurs
```

| Commission | Base |
|---|---|
| **CPFD** | Plus fort découvert **de CHAQUE MOIS CIVIL**, additionnés |
| **Dépassement** | (découvert − plafond négocié) par mois civil, si > 0 |
| **De compte** | (mouvements débiteurs − exonérés) × taux |

⚠️ **« du X inclus au Y inclus » → compter les DEUX bornes.**

## ★ Arbitrage escompte / découvert

```
1. Effets éligibles = échéance POSTÉRIEURE à la fin du déficit
2. Prendre les échéances les PLUS PROCHES, jusqu'à couvrir le besoin
3. À couverture égale, PEU d'effets (commissions forfaitaires)
4. Comparer sur 2 critères : le COÛT EN € et le TAUX RÉEL EN %
5. Envisager la SOLUTION MIXTE (souvent la moins chère)
```

**Les 2 critères peuvent se contredire** : l'escompte **sur-finance** (VN entière, durée entière) → son taux réel peut être plus bas alors que son coût absolu est plus élevé.

> *« Le découvert est un mode de financement plus souple, qui s'adapte à la durée et au montant exacts du besoin. »*

# CHAP. 7 — INTÉRÊTS COMPOSÉS

## Les 4 formules et leurs inversions

```
Cₙ = C₀ (1 + t)ⁿ              C₀ = Cₙ (1 + t)⁻ⁿ
n  = ln(Cₙ/C₀) / ln(1+t)      t  = (Cₙ/C₀)^(1/n) − 1
I  = C₀ [(1 + t)ⁿ − 1]
```

## Taux proportionnels vs équivalents

```
PROPORTIONNEL :  ts = ta/2   ·   tt = ta/4   ·   tm = ta/12

ÉQUIVALENT    :  (1 + t_court)^k = (1 + t_long)

     ts = (1+ta)^(1/2) − 1        ta = (1+ts)² − 1
     tt = (1+ta)^(1/4) − 1        ta = (1+tt)⁴ − 1
     tm = (1+ta)^(1/12) − 1       ta = (1+tm)¹² − 1
                                  t_trim = (1+tm)³ − 1
```

| | Usage |
|---|---|
| **Proportionnel** | < 1 an (escompte, découvert). Les banques l'utilisent pour les **emprunts**. |
| **Équivalent** | > 1 an. Utilisé pour les **placements**. |

**Contrôle** : le taux équivalent annuel est toujours **légèrement supérieur** au taux proportionnel.

## Équivalence de capitaux

```
1. TRACER L'AXE DU TEMPS (flux + dates + signes)
2. Choisir une date de référence
3. Σ (flux entrants actualisés) = Σ (flux sortants actualisés)
4. Résoudre
```

## ★ Le second degré (quand l'énoncé rappelle le discriminant)

```
1. Poser  x = (1+t)⁻¹   ou   x = (1+t)ⁿ
2. Obtenir  ax² + bx + c = 0
3. Δ = b² − 4ac   ·   x = (−b ± √Δ)/2a
4. ÉCARTER la racine qui donne un taux négatif ou x < 0
5. Revenir à t
```

## Interpolation linéaire

Quand l'énoncé dit *« taux compris entre A et B »* :
```
1. Calculer la valeur pour A → V₁       2. Calculer pour B → V₂

                    (t₁ − t₂) × (V₁ − Vcible)
     t  =  t₁  −  ──────────────────────────────
                          V₁ − V₂
```
**Contrôle** : le taux trouvé doit être **dans l'intervalle annoncé**. Sinon, erreur de sens.

## Suites d'annuités

```
Valeur ACQUISE  :  Vₙ = a × [(1+t)ⁿ − 1] / t
Valeur ACTUELLE :  V₀ = a × [1 − (1+t)⁻ⁿ] / t

a = V₀ × t / [1 − (1+t)⁻ⁿ]        a = Vₙ × t / [(1+t)ⁿ − 1]
n = −ln(1 − V₀t/a) / ln(1+t)      n = ln(1 + Vₙt/a) / ln(1+t)
```
*Retraits ou versements à intervalles irréguliers → les capitaliser UN PAR UN jusqu'à la date finale.*

# 📝 BOÎTE À PHRASES POUR LES COMMENTAIRES

**Structure en 4 temps : CONSTAT → EXPLICATION → NUANCE → RECOMMANDATION**

**Équilibre financier**
> *« Le FRNG est positif et couvre [largement/partiellement] le BFR ; il en résulte une trésorerie [positive/négative]. Toutefois, cette situation n'est due qu'à un BFRHE négatif : sans cela, la trésorerie serait négative. »*

**Croissance**
> *« Le FRNG augmente, mais le BFR croît encore plus vite. Il en résulte une dégradation de la trésorerie. L'entreprise connaît une forte croissance, mais celle-ci n'est pas suffisamment maîtrisée. »*

**Trésorerie**
> *« Le montant de la trésorerie de passif devient préoccupant, car le banquier pourrait sans préavis interrompre ce type de financement. »*
> *« La trésorerie est pléthorique : l'entreprise ne fait pas fructifier ses liquidités. »*
> *« L'entreprise se trouve en état de cessation de paiements (actif < 1 an inférieur aux dettes < 1 an). »*

**Effet de levier**
> *« Tant que Re demeure supérieure au coût de la dette, plus l'entreprise s'endette, plus elle améliore sa rentabilité financière — jusqu'au seuil où le prêteur refuse un endettement excessif et élève son taux au-dessus de Re. L'effet de levier se transforme alors en effet de massue. »*

**Investissement**
> *« L'entreprise a beaucoup investi, surtout par croissance interne, sans qu'il s'agisse d'un renouvellement de son outil de production : il s'agit d'accroître ses capacités productives pour gagner des parts de marché. »*

**BFR normatif**
> *« Le BFR normatif représente X jours de CAHT, contre Y jours en moyenne dans le secteur. Si l'entreprise s'alignait sur le secteur, elle économiserait Z € de trésorerie. »*

**Les 4 questions à te poser systématiquement**
```
1. La trésorerie est-elle positive, et POURQUOI ?
2. Y a-t-il des CBC ? (leur apparition est TOUJOURS à signaler)
3. Qui finance ? (activité / actionnaires / banques)
4. Quelle nature de croissance ? (interne / externe / renouvellement)
```

## 🎯 EN CAS DE BLOCAGE

1. **Écris la formule.** Même sans les chiffres, elle rapporte des points.
2. **Passe à la question suivante.** Les questions sont souvent indépendantes.
3. **Si tu ne trouves pas une donnée**, invente-la explicitement : *« Faute de l'information X, je retiens l'hypothèse Y »* — puis continue. Le correcteur note la méthode.
4. **Pour une inconnue inhabituelle** : écris la formule dans le sens du cours, remplace tout ce que tu connais, il reste une lettre. **C'est du collège à partir de là.**
